# Express User Management API

Este é um projeto de treino para aprender a programar e construir APIs REST simples usando Node.js, Express e SQLite.  

Aqui, estou praticando conceitos importantes como autenticação JWT, hashing de senhas e manipulação de rotas para gerenciamento básico de usuários.

## Funcionalidades

- Cadastro, listagem, atualização e remoção de usuários
- Validação básica dos dados enviados
- Senhas armazenadas com hash usando bcryptjs
- Autenticação via JSON Web Tokens (JWT)
- Banco de dados SQLite integrado

## Tecnologias usadas

- Node.js
- Express
- SQLite
- bcryptjs
- jsonwebtoken

## Como usar

1. Clone o repositório  
   `git clone https://github.com/seu-usuario/nome-do-repositorio.git`

2. Entre na pasta do projeto  
   `cd nome-do-repositorio`

3. Instale as dependências  
   `npm install`

4. Inicie o servidor  
   `node app.js` ou `nodemon app.js`

5. Teste as rotas usando Postman ou outra ferramenta

## Estrutura

- `app.js` — Arquivo principal com as rotas
- `database/` — Banco de dados SQLite e configuração
